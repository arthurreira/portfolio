## O que construí

Um pipeline completo de IoT, do hardware físico até um dashboard web com dados em tempo real. O microcontrolador ESP32 lê continuamente dois sensores: o BME280 mede temperatura, umidade e pressão atmosférica, enquanto o DHT11 serve como referência secundária. O firmware foi escrito em C++ na Arduino IDE e configurado para enviar as leituras por POST a um endpoint PHP em intervalos definidos.

O backend é um script PHP executado em uma instância local do WampServer. Ele recebe o POST, valida o payload e grava os dados no MySQL. O dashboard lê o mesmo banco e atualiza automaticamente a cada 30 segundos para mostrar as medições mais recentes, com a interface estilizada em MDB Bootstrap.

## O que aprendi

Este foi o primeiro projeto em que precisei pensar simultaneamente em três camadas separadas: hardware — fiação, protocolos dos sensores e firmware —, pipeline de dados no backend — HTTP POST, PHP e MySQL — e exibição no frontend. O debug foi mais difícil do que em qualquer projeto puramente de software, porque o problema podia estar no circuito, no firmware, no PHP ou no SQL.

## Destaques

- ESP32 lê os sensores BME280 e DHT11 a cada 30 segundos
- Firmware envia JSON por POST a um endpoint PHP
- PHP valida os dados e grava no MySQL
- Dashboard atualiza temperatura, umidade e pressão automaticamente
- Pipeline completo de hardware → backend → frontend

## Stack tecnológica

- **Hardware:** ESP32 + BME280 + DHT11
- **Firmware:** Arduino IDE (C++)
- **Backend:** PHP + MySQL (WampServer)
- **Frontend:** JavaScript + MDB Bootstrap
