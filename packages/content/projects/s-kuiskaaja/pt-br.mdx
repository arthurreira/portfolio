## What I built

A complete IoT pipeline from physical hardware to a live web dashboard. The ESP32 microcontroller reads environmental data continuously via two sensors: the BME280 for temperature, humidity, and barometric pressure, and the DHT11 as a secondary reference. Firmware was written in Arduino IDE (C++) and configured to POST sensor readings to a PHP endpoint at a set interval.

The backend is a PHP script running on a local WampServer instance. It receives the POST, validates the payload, and writes to a MySQL database. The frontend dashboard reads from the same database and auto-refreshes every 30 seconds to show the latest readings — styled with MDB Bootstrap.

## What I learned

This project was the first time I had to think about three completely separate layers at once: hardware (wiring, sensor protocols, firmware), a backend data pipeline (HTTP POST, PHP, MySQL), and a frontend display — all working together. Debugging was harder than any pure software project because a bug could live in the circuit, the firmware, the PHP, or the SQL.
