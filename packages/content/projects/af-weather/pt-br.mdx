## O que construí

Um app de clima que mostra as condições atuais e a previsão dos próximos dias para seis cidades: Helsinki, Tampere e Oulu, na Finlândia, além de São Paulo, Fortaleza e Curitiba, no Brasil. O app usa a API Open-Meteo, que é gratuita e não exige chave de API.

O projeto fica no mesmo monorepo Turborepo do portfolio e consome o pacote de tokens de design `@arthurreira/ui`. Assim, cores, tipografia e espaçamento permanecem sincronizados automaticamente com o portfolio. A arquitetura de rotas separa páginas estáticas para cada cidade do endpoint dinâmico `/api/weather`, que busca dados atualizados a cada requisição.

## O que aprendi

O principal aprendizado veio do compartilhamento de tokens de design em um monorepo: o padrão funciona bem até que um dos apps precise se afastar do sistema. Descobrir como sobrescrever tokens sem quebrar o pacote compartilhado me ensinou onde devem ficar os limites de um sistema comum.

## Destaques

- Previsão ao vivo para seis cidades — Helsinki, Tampere, Oulu, São Paulo, Fortaleza e Curitiba
- API Open-Meteo gratuita e sem chave de API
- Pacote de tokens de design `@arthurreira/ui` compartilhado com o portfolio
- Páginas estáticas por cidade e endpoint dinâmico `/api/weather`
- Alternância de modo escuro, disponível em [weather.arthurreira.dev](https://weather.arthurreira.dev)

## Stack tecnológica

- **Framework:** Next.js 15 (App Router)
- **Linguagem:** TypeScript
- **Dados:** Open-Meteo API
- **Monorepo:** Turborepo + pnpm workspaces
- **Estilos:** Tailwind CSS + tokens do `@arthurreira/ui`
