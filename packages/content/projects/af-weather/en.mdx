**AF Weather** is a minimalist weather application that displays current conditions and forecasts for a curated set of Finnish and Brazilian cities. It uses the free [Open-Meteo API](https://open-meteo.com/) for weather data — no API key required.

## Features

- Current temperature, wind speed, and weather condition
- Hourly and daily forecast views
- Cities in Finland (Helsinki, Tampere, Oulu) and Brazil (São Paulo, Fortaleza, Curitiba)
- Fully responsive layout built with Tailwind CSS
- Deployed at a custom domain

## Tech Stack

- **Next.js 15** — App Router, Server Components
- **TypeScript** — end-to-end type safety
- **Tailwind CSS** — utility-first styling
- **Open-Meteo API** — free, no-key weather data
