**infra** é um **sistema de automação Terraform** para criar e gerenciar múltiplos repositórios GitHub Pages com subdomínios personalizados.

Automatiza todo o processo de configuração da infraestrutura, desde a criação do repositório até a configuração do Pages e geração do workflow de deploy.

## Funcionalidades principais

1. **Criação automatizada de repositórios:** Cria repositórios GitHub com visibilidade (público/privado) e convenções de nomenclatura definidas.
2. **Configuração do GitHub Pages:** Habilita o GitHub Pages automaticamente via Terraform usando um Personal Access Token com permissões de admin.
3. **Domínio personalizado:** Gera arquivos CNAME para subdomínios personalizados (ex: `register.arthurreira.dev`, `schedule.arthurreira.dev`).
4. **Workflows de deploy:** Gera automaticamente workflows do GitHub Actions para cada repositório, que constroem e fazem deploy do conteúdo estático para o Pages.
5. **Operações idempotentes:** Inclui importação automática de repositórios para evitar erros de recriação em re-execuções.

## Arquitetura

O sistema é composto por dois componentes principais:

1. **Infraestrutura Terraform (repo infra):**
   - Cria repositórios GitHub
   - Habilita o GitHub Pages
   - Define domínios personalizados via arquivos CNAME
   - Gera workflows de deploy
   - Importa repos existentes para evitar recriação

2. **Workflows de deploy (repos das apps):**
   - Disparam automaticamente em push para a branch principal
   - Constroem o conteúdo estático
   - Fazem upload e deploy para o Pages
   - Executam com permissões padrão do GitHub Actions

## Tecnologias

- **Infraestrutura:** Terraform >= 1.5
- **Provider:** `integrations/github` ~> 6.0
- **Automação:** GitHub Actions
- **Deploy:** GitHub Pages

## Uso

**Local:**
```bash
export TF_VAR_github_owner="arthurreira"
export TF_VAR_github_token="ghp_yourClassicPAT"

terraform -chdir=infra init
terraform -chdir=infra apply
```

**GitHub Actions:**
- Configure o secret `GH_PAT` com Classic PAT (escopos repo + delete_repo)
- Execute o workflow pela aba Actions
- Ative `apply` para executar as alterações
