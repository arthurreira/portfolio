## What I built

A Unity VR game built for physical rehabilitation, targeting users recovering from conditions that affect arm mobility and coordination. The core mechanic is simple by design: pick up virtual trash and throw it into the correct bins. The throwing motion naturally engages the shoulder, elbow, and wrist — the same movements that physical therapists target in recovery programmes.

The game has three difficulty levels that change object weight, bin distance, and the variety of trash types. Real-time feedback shows the player how accurate each throw was, giving the sense of progress that keeps rehabilitation engaging.

## What I learned

Designing for rehabilitation is a fundamentally different constraint from designing for entertainment. The movements needed to be hard enough to be therapeutic but not so demanding that a patient in recovery would fail and give up. It was also the first time I built something where the user's physical safety mattered more than fun, which changes how you think about every design decision.
