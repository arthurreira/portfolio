**hackathon-projects** on **staattinen verkkosovellus** hackathon-projektilähetysten esittelyyn, julkaistu GitHub Pagesin kautta.

Se tarjoaa keskitetyn alustan, jossa osallistujat ja tuomarit voivat selata ja katsoa kaikki lähetetyt hackathon-projektit organisoidussa, helposti saatavilla olevassa muodossa.

## Tärkeimmät ominaisuudet

1. **Projektiesittely:** Näyttää kaikki hackathon-projektilähetykset tiedoin, kuvauksin ja linkkeineen.
2. **Automaattinen julkaisu:** GitHub Actions -työnkulku rakentaa ja julkaisee sivuston automaattisesti jokaisella commitilla päähaaran.
3. **Mukautettu domain:** Julkaistu osoitteessa `projects.arthurreira.dev` mukautetun alidomainin kautta.
4. **Helpot päivitykset:** Järjestäjät voivat lisätä tai päivittää projektilistauksia muokkaamalla tiedostoja ja tekemällä commitin — ei manuaalista julkaisua tarvita.
5. **Infrastruktuuriautomaatio:** Luotu ja konfiguroitu automaattisesti Terraform-infrastruktuuriautomaation kautta.

## Teknologiat

- **Julkaisu:** GitHub Pages
- **Automaatio:** GitHub Actions
- **Infrastruktuuri:** Terraform
- **Domain:** Mukautettu alidomaini (projects.arthurreira.dev)

## Arkkitehtuuri

Sovellus on osa automatisoitua infrastruktuurijärjestelmää:

1. **Infrastruktuurin provisiointi:** Luotu automaattisesti `infra` Terraform-projektin toimesta
2. **Repon asetus:** GitHub-repo, jossa Pages on käytössä ja mukautettu domain konfiguroitu
3. **Julkaisutyönkulku:** Automaattisesti generoitu GitHub Actions -työnkulku hallitsee rakennuksia ja julkaisuja
4. **Sisällönhallinta:** Staattiset tiedostot, joita voidaan helposti päivittää Git-commiteilla
