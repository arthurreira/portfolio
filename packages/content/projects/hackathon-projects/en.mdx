## What I built

A static project-showcase site — one of three apps in a Terraform infrastructure demo. It displays hackathon project submissions in an organised gallery. The real engineering is the automation: this site, plus `hackathon-registration` and `hackathon-schedule`, are all provisioned by a single Terraform module that creates the GitHub repo, enables Pages, configures the custom subdomain, and generates the deploy workflow.

## What I learned

See [hackathon-registration](/projects/hackathon-registration) for the full write-up on the Terraform automation behind all three sites — the GitHub provider quirks and what infrastructure-as-code is really for.
