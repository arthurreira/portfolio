**hackathon-projects** is a **static web application** for showcasing hackathon project submissions, deployed via GitHub Pages.

It provides a centralized platform where participants and judges can browse and view all submitted hackathon projects in an organized, accessible format.

## Key Features

1. **Project Showcase:** Displays all hackathon project submissions with details, descriptions, and links.
2. **Automatic Deployment:** GitHub Actions workflow automatically builds and deploys the site on every commit to the main branch.
3. **Custom Domain:** Deployed at `projects.arthurreira.dev` via custom subdomain configuration.
4. **Easy Updates:** Organizers can add or update project listings by editing files and committing changes - no manual deployment needed.
5. **Infrastructure Automation:** Created and configured automatically via Terraform infrastructure automation.

## Tech Stack

- **Deployment:** GitHub Pages
- **Automation:** GitHub Actions
- **Infrastructure:** Provisioned via Terraform
- **Domain:** Custom subdomain (projects.arthurreira.dev)

## Architecture

The application is part of an automated infrastructure system:

1. **Infrastructure Provisioning:** Created automatically by the `infra` Terraform project
2. **Repository Setup:** GitHub repository with Pages enabled and custom domain configured
3. **Deployment Workflow:** Auto-generated GitHub Actions workflow handles builds and deployments
4. **Content Management:** Static files that can be easily updated via Git commits
