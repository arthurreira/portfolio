**Sky Art Studio** é um site profissional criado para um estúdio de arte. Apresenta obras, fornece informações sobre o estúdio e permite que potenciais clientes entrem em contato.

O site foi projetado para ser visualmente atraente e fácil de navegar, com um layout limpo e moderno, otimizado para dispositivos móveis, tablets e desktops.

## Funcionalidades principais

### Página inicial
- Uma página inicial visualmente rica, exibindo as obras e serviços mais recentes.

### Galeria
- Exibe uma coleção curada de obras em um formato de galeria fácil de navegar.

### Página de contato
- Os clientes podem contatar o estúdio para consultas ou encomendas, incluindo um formulário de contato.

### Página de serviços
- Informações sobre os serviços oferecidos, incluindo encomendas de arte e workshops.

### Design responsivo
- Totalmente otimizado para todos os dispositivos: desktop, tablet e mobile.

## Tecnologias utilizadas

- **Plataforma:** WordPress
- **Estilo:** CSS personalizado para um design único
- **Plugins:** Contact Form 7, Yoast SEO
