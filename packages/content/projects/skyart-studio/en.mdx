**Sky Art Studio** is a professional website created for an art studio. It showcases artwork, provides information about the studio, and allows potential clients to get in touch.

The website is designed to be visually appealing and easy to navigate. It features a clean, modern layout, optimized for mobile, tablet, and desktop devices.

## Key Features

### Homepage
- A visually rich homepage showcasing the latest artwork and services.

### Gallery
- Displays a curated collection of artwork in an easy-to-navigate gallery format.

### Contact Page
- Clients can contact the studio for inquiries or commissions, including a contact form.

### Services Page
- Information about the services offered, including art commissions and workshops.

### Responsive Design
- Fully optimized for all devices: desktop, tablet, and mobile.

## Technologies Used

- **Platform**: WordPress
- **Styling**: Custom CSS for a unique design
- **Plugins**: Contact Form 7, Yoast SEO
