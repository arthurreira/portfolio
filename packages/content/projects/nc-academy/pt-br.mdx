## O que construí

Oito módulos práticos concluídos durante a Nordcloud Academy for IT Administrators — um programa estruturado de cloud engineering realizado internamente na Nordcloud. Cada módulo tinha seu próprio repositório:

- **Azure Bicep** — deploy de recursos reais no Azure usando templates Bicep
- **Terraform** — provisionamento de ambientes de nuvem com HCL, incluindo gerenciamento de estado, módulos e particularidades do provider Azure
- **Python** — scripts, tarefas de automação e exercícios de processamento de dados com APIs de nuvem
- **C# REST API** — backend .NET expondo o banco Northwind como REST API com endpoints CRUD completos
- **Dashboard React** — frontend consumindo a API do Northwind e mostrando métricas de pedidos, clientes e receita
- **Arquitetura de autenticação** — desenho de fluxos com OAuth 2.0, JWT e acesso baseado em papéis
- **Implementação de autenticação** — aplicação prática da arquitetura desenhada no módulo anterior
- **Integração** — conexão de toda a stack: frontend React → API C# → banco Northwind, com autenticação protegendo o fluxo completo

## O que aprendi

A estrutura do programa mostrou como todas as partes de uma stack estão conectadas. Escrever o Bicep que provisiona a infraestrutura onde roda a API .NET, que atende ao dashboard React protegido pelo módulo de autenticação, torna cada decisão visível. Infraestrutura de nuvem e código da aplicação não são assuntos separados — a IaC define o que é possível na camada da aplicação.
