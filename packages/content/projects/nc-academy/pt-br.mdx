**NC Academy** é um conjunto de projetos desenvolvidos durante o programa de treinamento **Nordcloud Academy**. Cada módulo focou em uma área diferente do desenvolvimento em nuvem, combinando teoria com exercícios práticos e hands-on.

## Módulos Abordados

### Infraestrutura em Nuvem
- **Bicep** — templates do Azure Resource Manager em Bicep para provisionamento e gestão de recursos Azure
- **Terraform** — Infrastructure-as-Code com Terraform para ambientes em nuvem

### Desenvolvimento Backend
- **Python** — scripting, automação e exercícios de desenvolvimento de APIs
- **C#** — serviços backend baseados em .NET e implementações de APIs REST

### Desenvolvimento Frontend
- **React** — projetos de UI baseados em componentes, gerenciamento de estado e integração com APIs

## Aprendizados

- Experiência prática em toda a stack de desenvolvimento em nuvem
- Padrões reais de IaC para ambientes Azure
- Contato com paradigmas backend dinâmicos (Python) e estaticamente tipados (C#, TypeScript)
