**NC Academy** on kokoelma projekteja, jotka on suoritettu **Nordcloud Academy** -koulutusohjelman aikana. Jokainen moduuli keskittyi eri pilvikehityksen osa-alueeseen yhdistäen teorian käytännön harjoituksiin.

## Käydyt moduulit

### Pilvi-infrastruktuuri
- **Bicep** — Azure Resource Manager -mallit Bicepillä Azure-resurssien käyttöönottoon ja hallintaan
- **Terraform** — Infrastructure-as-Code Terraformilla pilvympäristöjen provisiointiin

### Backend-kehitys
- **Python** — skriptaus, automaatiotehtävät ja API-kehitysharjoitukset
- **C#** — .NET-pohjaiset backend-palvelut ja REST API -toteutukset

### Frontend-kehitys
- **React** — komponenttipohjaisia käyttöliittymäprojekteja, tilanhallintaa ja API-integraatioita

## Opitut asiat

- Käytännön kokemus koko pilviohjelmoinnin pinosta
- Reaalimaailman IaC-mallit Azure-ympäristöihin
- Tutustuminen sekä dynaamisiin (Python) että staattisesti tyypitettyihin (C#, TypeScript) backend-paradigmoihin
