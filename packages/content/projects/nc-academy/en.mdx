**NC Academy** is a set of projects completed during the **Nordcloud Academy** training program. Each module focused on a different area of cloud and software development, combining theory with practical, hands-on assignments.

## Modules Covered

### Cloud Infrastructure
- **Bicep** — Azure Resource Manager templates written in Bicep for deploying and managing Azure resources
- **Terraform** — Infrastructure-as-Code with Terraform for provisioning cloud environments

### Backend Development
- **Python** — scripting, automation tasks, and API development exercises
- **C#** — .NET-based backend services and REST API implementations

### Frontend Development
- **React** — component-based UI projects, state management, and API integration

## Key Takeaways

- Hands-on experience across the full cloud development stack
- Real-world IaC patterns for Azure environments
- Exposure to both dynamic (Python) and statically-typed (C#, TypeScript) backend paradigms
