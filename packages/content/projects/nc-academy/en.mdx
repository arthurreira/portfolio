## What I built

Eight practical modules completed during the Nordcloud Academy for IT Administrators — a structured cloud engineering programme run internally at Nordcloud. Each module had its own repository and focused on a specific part of the stack:

- **Azure Bicep** — deployed live Azure resources (storage, App Service, static sites) using Bicep templates
- **Terraform** — provisioned cloud environments using HCL; covered state management, modules, and Azure provider specifics
- **Python** — scripting, automation tasks, and data processing exercises against cloud APIs
- **C# REST API** — .NET backend exposing the Northwind database as a REST API with full CRUD endpoints
- **React dashboard** — frontend consuming the Northwind API, displaying business metrics (orders, customers, revenue)
- **Authentication architecture** — designed and implemented auth flows covering OAuth 2.0, JWT, and role-based access
- **Auth implementation** — practical implementation of the auth architecture from the previous module
- **Integration** — connected all the pieces: React frontend → C# API → Northwind database, with auth securing the full stack

## What I learned

The programme's structure — one module per discipline, each building on the previous — made it clear how much the full stack is actually interconnected. Writing the Bicep to provision the infrastructure that runs the .NET API that serves the React dashboard that the auth module secures: that chain makes every decision visible. The biggest single lesson was that cloud infrastructure and application code are not separate concerns — the IaC shapes what's possible in the application layer.
