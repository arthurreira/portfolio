## What I built

Two repos that work as one system. The backend runs on a Linux machine: an eBPF program attaches to the `sys_enter_openat` tracepoint and captures every file open event — PID, process name, filename — then writes it to SQLite. A FastAPI server exposes an `/ask` endpoint that takes a plain English question, queries the event database, and passes the results to a local phi3:mini model via Ollama to generate an answer.

The frontend is a Next.js chat UI that runs on a Mac, sends questions to the FastAPI backend over the local network, and shows the answers.

```
React chat UI (Mac)
    → HTTP POST to FastAPI (Linux machine)
        → SQLite query (real eBPF kernel events)
            → phi3:mini via Ollama (local AI)
                → answer
```

You can ask it: *"What is the most active process?"*, *"What is Docker doing?"*, *"Is there anything suspicious?"* — and get answers backed by real kernel data.

Zero cloud. Zero API costs. Kernel data never leaves the local network.

## What I learned

eBPF is the most direct way to observe what a Linux system is actually doing. Attaching to a tracepoint instead of polling `/proc` means you see everything — no sampling, no gaps. The engineering challenge was making that raw event stream useful: translating "capture every openat syscall" into answers to questions like "is anything suspicious?" required the SQL-to-LLM pipeline to summarise thousands of events into a useful sentence.

Running inference locally with Ollama + phi3:mini was a deliberate choice. It removes the latency of API calls, eliminates costs, and means the kernel data never leaves the machine — which matters when the data includes every file your system touches.

## Highlights

- eBPF tracepoint hook on `sys_enter_openat` — captures every file open event
- SQLite event store — queryable with SQL
- FastAPI `/ask` endpoint for natural language queries
- Local LLM inference via Ollama (phi3:mini) — no cloud, no API costs
- Next.js chat UI talks to the backend over local network
- Tested on kernel 6.17, Ubuntu 24

- **AI:** Ollama, phi3:mini (local inference)
- **Frontend:** Next.js 15, TypeScript, Tailwind CSS
