**AF Next.js Component Architecture** on harjoitusprojekti **atomisen suunnittelun** periaatteiden tutkimiseen ja soveltamiseen Next.js-monorepossa. Tavoitteena oli rakentaa organisoitu, skaalautuva komponenttijärjestelmä alusta asti modernilla työkaluketjulla.

## Tavoitteet

- Harjoitella **atomit → molekyylit → organismit → mallipohjat → sivut** -hierarkiaa
- Ymmärtää, kuinka komponenttikirjasto rakennetaan pnpm-työtilaan
- Soveltaa TypeScriptiä tiukasti kaikkiin komponenttien propseihin ja apufunktioihin
- Pitää komponentit eristettyinä, yhdistelyyn soveltuvina ja helposti testattavina

## Rakenne

```
packages/
  ui/           # Jaettu komponenttikirjasto (atomit, molekyylit, organismit)
apps/
  playground/   # Next.js-sovellus komponenttien esittelyyn ja testaukseen
```

## Harjoitellut käsitteet

- **Atominen suunnittelu** — komponentit ryhmiteltynä monimutkaisuuden ja vastuun mukaan
- **pnpm workspaces** — monorepomäärittely jaettujen pakettien kanssa
- **TypeScript** — tiukka propsien tyypitys ja uudelleenkäytettävät rajapintamäärittelyt
- **Tailwind CSS** — utility-luokat komponenttitasolla

## Teknologiat

- **Next.js** — playground-sovelluskehys
- **TypeScript** — kattava tyyppiturvallisuus
- **pnpm** — nopea pakettienhallinta työtila-tuella
- **Tailwind CSS** — utility-first-tyylittely
