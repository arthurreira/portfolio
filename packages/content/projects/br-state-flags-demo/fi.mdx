**br-state-flags Demo** on verkkosivu, joka esittelee [br-state-flags-kirjaston](/projects/br-state-flags) toimintaa. Se mahdollistaa kaikkien 27 Brasilian osavaltiolipun selaamisen, niiden metatietojen tarkastelun (pääkaupunki, väestö, alue) ja lopputuloksen näkemisen tuotantoympäristössä.

## Ominaisuudet

1. **Interaktiivinen lippugalleria:** Katso kaikki liput responsiivisessa ruudukossa.
2. **Osavaltion tiedot:** Klikkaa mitä tahansa lippua nähdäksesi yksityiskohtaiset demografiset ja maantieteelliset tiedot kirjaston metadatasta.
3. **Koodiesimerkit:** Tarjoaa välittömät käyttöesimerkit jokaiselle osavaltion lippukomponentille.
4. **Tumma tila:** Täysin teemoitettu sekä vaalealle että tummalle ympäristölle.

## Teknologiat

- **Framework:** Next.js (App Router)
- **Tyyli:** Tailwind CSS
- **Kirjasto:** br-state-flags
- **Julkaisu:** GitHub Pages
