## What I built

The demo site for `br-state-flags`. A developer landing page that does three things: shows every flag in a browsable grid, displays the geographic and demographic metadata for each state on click, and generates ready-to-copy import snippets for whichever flag you're looking at. The site is the library's primary documentation.

## What I learned

A demo site is part of the product. A library that's hard to evaluate doesn't get adopted. The design challenge was making it feel like a reference tool (fast, functional, skimmable) rather than a portfolio piece. I also learned that demos need to stay in sync with the library — broken examples are worse than no examples.

## Highlights

- Browsable gallery of all 27 state flags
- Click any flag for capital, population, and region data
- Instant copy-ready import snippets per component
- Dark mode support
- Serves as the library's primary documentation

## Tech Stack

- **Framework:** Next.js (App Router)
- **Styling:** Tailwind CSS
- **Library:** br-state-flags
