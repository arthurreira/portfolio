O **br-state-flags Demo** é uma vitrine web para a [biblioteca br-state-flags](/projects/br-state-flags). Permite navegar por todas as 27 bandeiras dos estados brasileiros, inspecionar seus metadados (capital, população, região) e ver como ficam em um ambiente de produção.

## Funcionalidades

1. **Galeria interativa de bandeiras:** Veja todas as bandeiras em uma grade responsiva.
2. **Detalhes do estado:** Clique em qualquer bandeira para ver informações demográficas e geográficas detalhadas dos metadados da biblioteca.
3. **Exemplos de código:** Fornece exemplos de uso instantâneos para cada componente de bandeira.
4. **Modo escuro:** Totalmente temático para ambientes claro e escuro.

## Tecnologias

- **Framework:** Next.js (App Router)
- **Estilo:** Tailwind CSS
- **Biblioteca:** br-state-flags
- **Deploy:** GitHub Pages
