The **br-state-flags Demo** is a web-based showcase for the [br-state-flags library](/projects/br-state-flags). It allows users to browse all 27 Brazilian state flags, inspect their metadata (such as capital, population, and region), and see how they look in a production environment.

## Features

1.  **Interactive Flag Gallery:** View all flags in a responsive grid.
2.  **State Details:** Click on any flag to see detailed demographic and geographic information sourced directly from the library's metadata.
3.  **Code Snippets:** provides instant usage examples for each state flag component.
4.  **Dark Mode Support:** Fully themed for both light and dark environments.

## Tech Stack

-   **Framework:** Next.js (App Router)
-   **Styling:** Tailwind CSS
-   **Library:** br-state-flags
-   **Deployment:** GitHub Pages
