## What I built

A DNS lookup tool that lets you query any domain for six record types: A, AAAA, MX, TXT, CNAME, and NS. The interface is built with Next.js and shadcn/ui — enter a domain, pick a record type, get structured results immediately. A query history panel on the right tracks previous lookups so you can compare results without re-typing.

The DNS resolution runs on an AWS Lambda function rather than the Next.js server. The frontend calls an API route that proxies to the Lambda, which performs the actual DNS queries. The whole stack deploys to `dns.arthurreira.dev`.

## What I learned

The main engineering challenge was latency — DNS resolution involves unpredictable network round-trips and Lambda cold-start penalties. Reducing that required understanding Lambda provisioned concurrency, the trade-off between keeping functions warm and cost, and how to structure the API route to return a loading state immediately while resolution completes.
