## O que construí

Uma ferramenta de consulta DNS que permite pesquisar qualquer domínio em seis tipos de registro: A, AAAA, MX, TXT, CNAME e NS. A interface usa Next.js e shadcn/ui: basta informar um domínio, escolher o tipo de registro e receber os resultados estruturados. Um painel de histórico à direita mantém as consultas anteriores para comparar resultados sem digitar tudo novamente.

A resolução DNS acontece em uma função AWS Lambda, não no servidor Next.js. O frontend chama uma rota de API que encaminha a requisição para a Lambda, responsável pelas consultas DNS. A stack completa tem deploy em `dns.arthurreira.dev`.

## O que aprendi

O principal desafio técnico foi a latência: a resolução DNS envolve viagens de rede imprevisíveis e a penalidade da inicialização a frio da Lambda. Reduzir esse impacto exigiu entender a concorrência provisionada, o equilíbrio entre manter funções aquecidas e controlar custos e como estruturar a rota de API para mostrar imediatamente um estado de carregamento enquanto a resolução termina.

## Destaques

- Consulta de registros A, AAAA, MX, TXT, CNAME e NS para qualquer domínio
- Histórico de consultas para comparar resultados sem digitar novamente
- Resolução DNS serverless na AWS Lambda
- Estado de erro específico para NXDOMAIN, SERVFAIL e timeout
- Disponível em [dns.arthurreira.dev](https://dns.arthurreira.dev)

## Stack tecnológica

- **Frontend:** Next.js, TypeScript, shadcn/ui, Tailwind CSS
- **Backend:** AWS Lambda
- **Deploy:** Vercel + AWS
