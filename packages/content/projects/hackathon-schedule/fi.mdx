**hackathon-schedule** on **staattinen verkkosovellus** hackathon-tapahtumien aikataulujen näyttämiseen, julkaistu GitHub Pagesin kautta.

Se tarjoaa keskitetyn, helposti saatavilla olevan aikataulun, jonka osallistujat voivat katsoa nähdäkseen tapahtuma-aikataulut, sessiot, työpajat ja aktiviteetit.

## Tärkeimmät ominaisuudet

1. **Tapahtumaaikataulu:** Näyttää hackathon-aikataulun sessioineen, työpajoineen ja tärkeimpine aktiviteetteineen ajanmukaisen järjestyksen mukaan.
2. **Automaattinen julkaisu:** GitHub Actions -työnkulku rakentaa ja julkaisee sivuston automaattisesti jokaisella commitilla päähaaran.
3. **Mukautettu domain:** Julkaistu osoitteessa `schedule.arthurreira.dev` mukautetun alidomainin kautta.
4. **Helpot päivitykset:** Järjestäjät voivat päivittää aikataulua muokkaamalla tiedostoja ja tekemällä commitin — ei manuaalista julkaisua tarvita.
5. **Infrastruktuuriautomaatio:** Luotu ja konfiguroitu automaattisesti Terraform-infrastruktuuriautomaation kautta.

## Teknologiat

- **Julkaisu:** GitHub Pages
- **Automaatio:** GitHub Actions
- **Infrastruktuuri:** Terraform
- **Domain:** Mukautettu alidomaini (schedule.arthurreira.dev)
