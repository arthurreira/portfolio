## What I built

A static event-schedule site — one of three apps in a Terraform infrastructure demo. It displays the hackathon timeline. Like its companions, it isn't provisioned by hand: a single Terraform module creates the GitHub repo, enables Pages, sets the custom subdomain, and wires up the CD workflow.
