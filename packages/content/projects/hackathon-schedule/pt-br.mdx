**hackathon-schedule** é uma **aplicação web estática** para exibir a programação de eventos de hackathons, implantada via GitHub Pages.

Fornece uma programação centralizada e facilmente acessível que os participantes podem visualizar para ver cronogramas, sessões, workshops e atividades.

## Funcionalidades principais

1. **Exibição de cronograma:** Mostra a programação do hackathon com sessões, workshops e atividades-chave organizadas por horário.
2. **Deploy automático:** O workflow do GitHub Actions constrói e implanta o site automaticamente a cada commit na branch principal.
3. **Domínio personalizado:** Implantado em `schedule.arthurreira.dev` via configuração de subdomínio personalizado.
4. **Atualizações simples:** Os organizadores podem atualizar a programação editando arquivos e fazendo commit — sem deploy manual.
5. **Automação de infraestrutura:** Criado e configurado automaticamente pelo projeto Terraform de infraestrutura.

## Tecnologias

- **Deploy:** GitHub Pages
- **Automação:** GitHub Actions
- **Infraestrutura:** Terraform
- **Domínio:** Subdomínio personalizado (schedule.arthurreira.dev)
