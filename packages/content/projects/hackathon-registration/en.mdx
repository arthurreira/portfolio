**hackathon-registration** is a **static web application** for hackathon participant registration, deployed via GitHub Pages.

It provides a simple, accessible registration form that allows participants to sign up for hackathon events without requiring complex backend infrastructure.

## Key Features

1. **Registration Form:** Simple, user-friendly form for participants to register for hackathon events.
2. **Automatic Deployment:** GitHub Actions workflow automatically builds and deploys the site on every commit to the main branch.
3. **Custom Domain:** Deployed at `register.arthurreira.dev` via custom subdomain configuration.
4. **Easy Maintenance:** Registration form can be updated by editing files and committing changes - no manual deployment needed.
5. **Infrastructure Automation:** Created and configured automatically via Terraform infrastructure automation.

## Tech Stack

- **Deployment:** GitHub Pages
- **Automation:** GitHub Actions
- **Infrastructure:** Provisioned via Terraform
- **Domain:** Custom subdomain (register.arthurreira.dev)
