## What I built

This is not really a hackathon registration tool — it's an infrastructure demonstration. The real project is the Terraform automation that provisions it. Together with `hackathon-schedule` and `hackathon-projects`, these three static sites form a single showcase: one Terraform run creates three separate GitHub repositories, configures GitHub Pages on each, sets up custom subdomain DNS, and generates the GitHub Actions CD workflow — all without touching the GitHub UI.

## What I learned

The GitHub Terraform provider has a steeper learning curve than the AWS or Azure providers because GitHub's API is less predictable — rate limits, repository creation delays, and Pages configuration timing all require careful `depends_on` chains to work reliably. Writing Terraform that provisions other CI/CD pipelines taught me how infrastructure-as-code can manage not just servers but the entire deployment process.
