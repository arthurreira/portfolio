**hackathon-registration** é uma **aplicação web estática** para registro de participantes de hackathons, implantada via GitHub Pages.

Fornece um formulário de registro simples e acessível que permite aos participantes se inscreverem em eventos de hackathon sem precisar de infraestrutura de backend complexa.

## Funcionalidades principais

1. **Formulário de registro:** Formulário simples e intuitivo para os participantes se inscreverem nos eventos.
2. **Deploy automático:** O workflow do GitHub Actions constrói e implanta o site automaticamente a cada commit na branch principal.
3. **Domínio personalizado:** Implantado em `register.arthurreira.dev` via configuração de subdomínio personalizado.
4. **Fácil manutenção:** O formulário pode ser atualizado editando arquivos e fazendo commit — sem deploy manual.
5. **Automação de infraestrutura:** Criado e configurado automaticamente pelo projeto Terraform de infraestrutura.

## Tecnologias

- **Deploy:** GitHub Pages
- **Automação:** GitHub Actions
- **Infraestrutura:** Terraform
- **Domínio:** Subdomínio personalizado (register.arthurreira.dev)
