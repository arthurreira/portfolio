**hackathon-registration** on **staattinen verkkosovellus** hackathon-osallistujien rekisteröintiin, julkaistu GitHub Pagesin kautta.

Se tarjoaa yksinkertaisen, helposti saatavilla olevan rekisteröintilomakkeen, jonka kautta osallistujat voivat ilmoittautua hackathon-tapahtumiin ilman monimutkaista taustainfrastruktuuria.

## Tärkeimmät ominaisuudet

1. **Rekisteröintilomake:** Yksinkertainen, käyttäjäystävällinen lomake osallistujien ilmoittautumiseen.
2. **Automaattinen julkaisu:** GitHub Actions -työnkulku rakentaa ja julkaisee sivuston automaattisesti jokaisella commitilla päähaaran.
3. **Mukautettu domain:** Julkaistu osoitteessa `register.arthurreira.dev` mukautetun alidomainin kautta.
4. **Helppo ylläpito:** Rekisteröintilomaketta voi päivittää muokkaamalla tiedostoja ja tekemällä commitin — ei manuaalista julkaisua tarvita.
5. **Infrastruktuuriautomaatio:** Luotu ja konfiguroitu automaattisesti Terraform-infrastruktuuriautomaation kautta.

## Teknologiat

- **Julkaisu:** GitHub Pages
- **Automaatio:** GitHub Actions
- **Infrastruktuuri:** Terraform
- **Domain:** Mukautettu alidomaini (register.arthurreira.dev)
