**Acme Financial Dashboard** é uma aplicação de painel financeiro criada para **praticar e aprender Next.js**. Foi desenvolvida para explorar os recursos do Next.js, entender roteamento, busca de dados e padrões modernos de React. O projeto está agora **pronto para produção e totalmente funcional**.

## Status do projeto

**Status:** **Pronto para produção e totalmente funcional**

- Totalmente implantado e funcionando no Vercel
- Banco de dados inicializado e populado (Neon PostgreSQL)
- Autenticação funcionando corretamente (NextAuth.js v5)
- Todos os patches de segurança aplicados
- Analytics integrado (Vercel Analytics)
- Domínio personalizado configurado (arthurreira.dev)

**URL ao vivo:** [https://nextjs-dashboard.arthurreira.dev](https://nextjs-dashboard.arthurreira.dev)

## Objetivos de aprendizado

Este projeto serve como experiência prática para:
- Praticar a criação de aplicações com **Next.js 16**
- Entender server components, client components e o App Router
- Aprender sobre busca de dados, streaming e técnicas de otimização
- Praticar estilização com **Tailwind CSS**
- Explorar manipulação de formulários, validação e interações com o usuário
- Entender fluxos de autenticação (NextAuth.js)
- Praticar tratamento de erros e estados de carregamento

## Funcionalidades implementadas

### Gerenciamento de clientes
- Adicionar, atualizar e visualizar detalhes de clientes
- Listagem com busca e paginação

### Gerenciamento de faturas
- Criar, visualizar e atualizar faturas
- Rastreamento e gerenciamento de status de faturas

### Visão geral financeira
- Painel com estatísticas de receita
- Gráficos interativos para visualização de dados
- Rastreamento de valores coletados e pendentes
