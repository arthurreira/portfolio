## What I built

A meal kit service platform for the Finnish market — think HelloFresh but built from scratch in PHP and MySQL. Users can browse meals by dietary preference (Gluten-free, Keto, Vegan, Vegetarian, High-protein), build weekly plans, and place orders. An admin dashboard lets the operator manage products, categories, users, and orders. Full MVC architecture: separate controllers, models, and views for every feature area.

This was a school period final project with the goal of understanding how full-stack web applications work end-to-end without framework magic.

## What I learned

Building MVC from scratch in plain PHP is humbling. Without a framework enforcing patterns, you have to be deliberate about every routing decision, every SQL query, every session check. I learned why frameworks exist — not because the patterns are hard to understand, but because maintaining consistency across a large codebase without them requires real discipline. Database design was the other major lesson: normalising the relationships between meals, categories, dietary types, and orders before writing any code saved enormous refactoring later.
