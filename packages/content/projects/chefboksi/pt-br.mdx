## O que construí

Uma plataforma de kits de refeição para o mercado finlandês — semelhante ao HelloFresh, mas construída do zero com PHP e MySQL. Os usuários podem procurar refeições por preferência alimentar (sem glúten, cetogênica, vegana, vegetariana ou rica em proteína), montar planos semanais e fazer pedidos. Um dashboard administrativo permite gerenciar produtos, categorias, usuários e pedidos. A arquitetura segue MVC completo, com controllers, models e views separados para cada área.

Este foi o projeto final de um período escolar, feito para entender como aplicações web full-stack funcionam de ponta a ponta sem a abstração de um framework.

## O que aprendi

Construir MVC do zero em PHP puro exige atenção. Sem um framework impondo padrões, cada decisão de roteamento, consulta SQL e verificação de sessão precisa ser intencional. Entendi por que frameworks existem: não porque os padrões sejam difíceis de compreender, mas porque manter consistência em uma base de código grande sem eles exige muita disciplina. O outro grande aprendizado foi o desenho do banco de dados. Normalizar as relações entre refeições, categorias, dietas e pedidos antes de escrever o código evitou uma refatoração enorme depois.

## Destaques

- Busca de refeições por preferência alimentar
