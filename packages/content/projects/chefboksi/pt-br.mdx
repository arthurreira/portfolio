**ChefBoksi** é uma plataforma de kit de refeições (similar ao HelloFresh) construída com **PHP e MySQL** seguindo o padrão de arquitetura MVC.
Ajuda os usuários a selecionar refeições, personalizar planos semanais, acompanhar a nutrição e gerenciar entregas. A plataforma inclui um painel administrativo para gerenciar produtos, categorias, usuários e pedidos, com suporte a múltiplas preferências dietéticas (sem glúten, keto, vegano, vegetariano, etc.).

## Sobre o projeto

ChefBoksi.fi foi pensada para ser uma plataforma de entrega de kits de refeições para o mercado finlandês. A plataforma permite que os usuários selecionem refeições de diversas opções dietéticas, planejem refeições semanais, peçam ingredientes pré-porcionados com receitas e gerenciem endereços de entrega e rastreamento de pedidos.

Este foi um projeto de aprendizado focado em entender o desenvolvimento web full-stack, construir uma aplicação completa do frontend ao backend, trabalhar com bancos de dados e autenticação de usuários, implementar padrões de arquitetura MVC e ganhar experiência com PHP, MySQL, JavaScript e frameworks web modernos.

## Funcionalidades implementadas

- Autenticação de usuários (cadastro/login)
- Sistema de planejamento de refeições com filtros dietéticos
- Catálogo de produtos com categorias
- Funcionalidade de carrinho de compras
- Formulário de checkout
- Painel administrativo para gerenciar produtos, categorias, usuários e pedidos
- Sistema de rastreamento de pedidos
- Gerenciamento de endereço de entrega
- Suporte a múltiplas opções dietéticas (sem glúten, keto, vegetariano, vegano, alto teor proteico, etc.)

## Status do projeto

**Este projeto está incompleto e foi descontinuado.**

O projeto foi desenvolvido como trabalho final de um período escolar para obter uma compreensão mais profunda do desenvolvimento web full-stack. O projeto não foi concluído porque o desenvolvedor estava incerto sobre os próximos passos e a direção que queria dar ao projeto.
