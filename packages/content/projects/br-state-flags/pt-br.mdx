## O que construí

Um pacote npm com todas as 27 bandeiras dos estados brasileiros como componentes React SVG individuais — mais metadados enriquecidos (capital, população, região) para cada estado. Zero dependências. Funciona nativamente com Next.js, Vite e qualquer projeto React com TypeScript. Os SVGs foram otimizados para web: proporções consistentes, tamanhos de arquivo mínimos, cores oficiais precisas.

```bash
npm install br-state-flags
```

```tsx
import { SP, RJ } from 'br-state-flags'
<SP width={120} title="São Paulo" />
```

O site de demonstração em [br-state-flags-demo.arthurreira.dev](https://br-state-flags-demo.arthurreira.dev) funciona como a documentação principal da biblioteca — uma galeria navegável com todas as 27 bandeiras, metadados do estado ao clicar e snippets de importação prontos para copiar.

## O que aprendi

Publicar uma biblioteca no npm é diferente de construir um app. A superfície da API precisa ser estável — uma vez que você publica `import { SP }`, não dá para renomear. Aprendi sobre formatos de bundle (ESM vs CJS), o campo `exports` no package.json, e como escrever declarações TypeScript para que os consumidores tenham autocomplete. Otimização de SVG também foi novidade: SVGO remove metadados e reduz tamanhos de arquivo em 40-60% sem mudança visual.

Um site de demonstração faz parte do produto. Uma biblioteca difícil de avaliar não é adotada.
