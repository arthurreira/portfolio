## What I built

An npm package that ships all 27 Brazilian state flags as individual React SVG components — plus enriched metadata (capital, population, region) for each state. Zero dependencies. Works out of the box with Next.js, Vite, and any TypeScript React project. The SVGs were optimised for web: consistent aspect ratios, minimal file sizes, accurate official colours.

```bash
npm install br-state-flags
```

```tsx
import { SP, RJ } from 'br-state-flags'
<SP width={120} title="São Paulo" />
```

The demo site at [br-state-flags-demo.arthurreira.dev](https://br-state-flags-demo.arthurreira.dev) serves as the library's primary documentation — a browsable gallery of all 27 flags, state metadata on click, and copy-ready import snippets.

## What I learned

Publishing a library to npm is a different discipline from building an app. The API surface has to be stable — once you ship `import { SP }`, you can't rename it. I learned about bundle formats (ESM vs CJS), `exports` field in package.json, and how to write TypeScript declarations so consumers get autocomplete. SVG optimisation was also new: SVGO strips metadata and reduces file sizes by 40-60% without visual change.

A demo site is part of the product. A library that's hard to evaluate doesn't get adopted.
