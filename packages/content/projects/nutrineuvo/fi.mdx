## What I built

A nutrition and wellness platform with a proper production microservices architecture. Three services run in Docker Compose on an UpCloud server: a React marketing site (`nutrineuvo.fi`), a React application (`oma.nutrineuvo.fi`), and a Node.js/Express REST API. Nginx sits in front of everything as a reverse proxy, terminating SSL from Let's Encrypt and routing traffic to the right container. Terraform provisions the UpCloud server; GitHub Actions handles every deployment automatically on push to main.

## What I learned

Running microservices in production — not in a tutorial — requires solving a class of problems that local development hides. SSL certificate renewal, database backup scheduling, zero-downtime deployments, and environment variable management across multiple services all need explicit solutions. Nginx configuration also clicked differently once it was handling real traffic rather than being a dev proxy. The biggest lesson: infrastructure decisions made early (how you name containers, how you structure health checks) propagate through everything and are painful to change later.
